# Upstream source reference

The user supplied `erpnext-develop2.zip`, containing ERPNext `17.x.x-develop` from the upstream ERPNext project. This application is a browser-only educational adaptation informed by the supplied Chart of Accounts, Journal Entry, Purchase Order, Purchase Invoice, Sales Invoice, Item, stock, party and Employee DocTypes and the documented Frappe server requirements.
